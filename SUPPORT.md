# Support and governance

Sentient Sim is currently maintained by Henry Barrientos as a single-author open
research project. Scientific and software decisions are documented through the
public repository, version history, issue tracker, protocols, and release notes.

Use GitHub issues for reproducible bugs, documentation problems, proposed model
changes, or requests to reproduce a result. Include the revision, source and
protocol hashes, runtime versions, exact command, and seed when applicable.

This project is provided without guaranteed response times or operational
support. Do not use it for medical, safety-critical, legal, or production
decisions. Questions about whether a result demonstrates consciousness will be
answered within the claim boundary documented in the README and protocol.

Contributors should follow `CONTRIBUTING.md`. Any future change in maintainers or
decision process will be recorded here and in the changelog.
